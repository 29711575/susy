# P3：小系统耦合 Monte Carlo

按工作区的 `kitaev-ssh-p3-physics-and-prompt.md` 实施；不修改该输入推导文件。
新增 `phonon_mc.h`、`phase_statistics.h`、`coupled_mc.cpp`、`mc_validate.cpp`。
旧模型、P2 事务及共享数值层保持不变，CMake 增加运行/验证目标。

只用一种提议：自由声子的单坐标条件 Gaussian（端点含试探权重），其
正反提议比与声子 log 权重变化抵消。接受判据仅用 log|Wf_new/Wf_old|，
不是忽略声子权重。每扫掠随机排序并覆盖全部坐标，中心只更新一次。
调用 P2 的完整物理 Pfaffian 权重与方向适配，保留复相位。

热化与正式统计期间均不调整提议参数。每固定间隔扫掠测量，包括拒绝后
停留的状态。按方向输出中心 X、X²，另输出 Majorana 能量总和；**没有**
完整声子动能/总能量估计器。每块保存 count、sum(s)、sum(sO)。结果是
全部总和之比，误差使用联合 delete-one-block jackknife，分别报告实部/
虚部标准误和协方差。另报告相邻块合并后的误差，方便检查块长敏感性。

在发布源码目录，按现有 README 加载 oneAPI、Eigen/Boost、CMake 环境后：

```bash
cmake -S . -B build-kitaev-p01
cmake --build build-kitaev-p01 --target kitaev_ssh_mc_validate kitaev_ssh_mc --parallel 1
ctest --test-dir build-kitaev-p01 -R 'kitaev_ssh_p3|density_sign' --output-on-failure --parallel 1
export OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_DYNAMIC=FALSE
./build-kitaev-p01/kitaev_ssh_mc --Lx 2 --Ly 2 --intervals 4 --dt 0.2 \
  --mass 4 --omega-ph 0.5 --g 0.3 --seed 42 --warmup 100 --sweeps 400 \
  --measure-every 2 --block-samples 10 --output /tmp/ssh-kitaev-p3
```

输出 PREFIX_results.json 和 PREFIX_blocks.csv，不覆盖已有文件。
默认 J=(1,1,0.5)，可用 --Jx/--Jy/--Jz 指定；g、mass、omega-ph 为独立
输入，k、lambda 派生。intervals=M 必须为偶数，总时间 M*dt=2*Theta。
--sweeps 指热化后的扫掠数，必须整除测量间隔并形成完整等长块。
--qr-block 设置 P2 重建块长，与统计 --block-samples 无关。
种子驱动路径初始化及后续链，不隐式修改 gauge/边界来避开零模。

相位分母数值接近零时 ratio_defined=false；jackknife 不可算时误差为 null。
平均相位与零的距离须超过五倍复误差范数才标 phase_resolved_5sigma。
少于 16 块给 too_few_blocks 提醒；这不是独立样本数证明。所有运行均明示
block_independence_verified=false，不能凭块数或高接受率宣称统计收敛。
需增大块长/运行长度及多种子检查。数值失败明确终止而不伪装普通拒绝，
保留已完成的 CSV 块；P2 尚不能可靠区分所有真零重叠与数值秩失败。

验证只覆盖新采样环节：单键 Fock 接受率及实际接受/拒绝、g=0 与耦合
单键的采样均值/协方差、可精确求和的非平凡复相位累计与 jackknife。
下一步为 VBS 观测量和有针对性的尺寸、投影长度、步长及统计收敛检查。
当前中心位移或小系统数据不构成非公度 VBS 证据。
