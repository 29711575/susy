# P2 最小声子路径接口

沿用项目根目录 `kitaev-ssh-p2-physics-and-prompt.md` 的分解，无额外键分裂。
P2 默认 J=(1,1,0.5)，P1 自由入口的历史默认 Jz=0.6 不变。
独立输入为 g、mass、omega-ph；k=m*omega²、lambda=g²/k 仅派生报告，
不接受相互冲突的独立 lambda 输入。所有键位移为未重标度实数，不限制均值
或有效 hopping 的正负。结果限于固定 gauge matter sector。

- `phonon_path.h`：M 为偶数链路数，保存 X[0..M][bond]，总时间 M*dt=2*Theta。
  完整声子 log 权重含精确核常数和两端各一次归一化真空波函数；无时间闭合链路。
  局部变化仅读相邻节点及必要的端点项。freeSample 是自由声子归一化 AR 分布。
- `phonon_projector.h`：以作用顺序保存 2M 个未合并半步，每个为 exp(-dt*K_code(X)/2)。
  节点 j 的因子索引为 {2j-1,2j}，两端分别只有 {0} 和 {2M-1}。
  中心共享 X[M/2]，Green cut=M，恰在两个中心半步之间。
  调用 P1 修正过的 stabilized Pfaffian reference 得到 log|Wf| 和复相位；
  endpoint/QR/SVD 在中心重建 Green，不能假定独立 bra/ket 路径组成 U†U。
  非镜像 Fock 测试发现旧接口的方向约定：核心 oblique Green 需取伴随才是
  物理 -<c_i c_j>；Hermitian 半步的权重调用需逆序传给旧 reference routine。
  适配只作用于 P2，活跃因子仍按物理作用顺序保存，标量 eta 相位不共轭。
  另用含非二分图双线性项的小型 Fock 测试核验非实物理重叠相位，避免
  在当前实权重蜂窝样例上漏掉相位共轭错误。P1 镜像结果无需修改。
- `CoupledPhononPath::propose`：复制快照，只重新指数化受影响节点的矩阵，
  重建全部依赖权重/Green 缓存；fullReference 从全部坐标重建作为独立更新参考。
  accept 一次替换完整快照；reject 不动活跃状态。异常亦不提交，旧/外来/已消费
  proposal 明确拒绝。这是单线程事务接口，不是并发线程安全承诺。
- `phonon_validate.cpp`：解析 Gaussian、局部差分、事务、非镜像 2×2 Fock 中心
  Green，以及有耦合单键 eta=±1 的离散积分和二阶步长收敛。

在发布源码目录中，先按 README 设置 oneAPI、Eigen/Boost 和 CMake PATH：

```bash
cmake -S . -B build-kitaev-p01
cmake --build build-kitaev-p01 --target kitaev_ssh_phonon_validate kitaev_ssh_phonon_example --parallel 1
ctest --test-dir build-kitaev-p01 -R 'kitaev_ssh_p2|kitaev_ssh_p01|density_sign' --output-on-failure --parallel 1
export OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_DYNAMIC=FALSE
./build-kitaev-p01/kitaev_ssh_phonon_validate
./build-kitaev-p01/kitaev_ssh_phonon_example --g 0.3 --mass 4 --omega-ph 0.5
```

示例只生成自由路径并强制演示一次拒绝/接受，**不是耦合分布采样结果**。
可选 `--save FILE` / `--load FILE` 保存/读取坐标、声子参数及时间网格；
它不是包含 gauge、trial、g 或 RNG 的完整 MC checkpoint。
加载时显式给 g、几何；不允许同时覆盖文件中的质量、频率或网格。
步长二阶指固定总时间的声子—Majorana 对称分解；自由声子核本身无步长误差。

本轮没有改共享数值层、旧模型或旧入口。权重/重建遇到零重叠、不可信 Pfaffian
或条件数失败时抛错且保留原状态，不将数值失败伪装成 Metropolis 拒绝。
后续仍需：耦合 proposal 分布及正确提议密度比、以 |W| 采样时显式相位重加权、
扫掠/自相关与统计、长轮廓失败恢复和性能优化。一般零模占据与自旋投影未加入。
