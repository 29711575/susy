# P4: center-node bond structure factors

`kitaev_ssh_mc --vbs 1` adds cell Fourier measurements to the existing physical
Pfaffian / conditional-Gaussian MC; `--vbs 0` (default) retains the P3 outputs.
`--shear 0` is the existing axis-aligned PBC. A nonzero integer `--shear`
changes the spatial quotient and therefore the seam bonds, matter Hamiltonian,
free trial state and generally the sampled finite-size ensemble. It is not a
continuous U(1) twist. The local proposal remains the default; an optional
bond refresh is described below.

For `Nc=Lx*Ly`, `q=u*b1+v*b2` with
`u=n1/Lx`, `v=n2/Ly-shear*n1/(Lx*Ly)`, each A-cell contributes exactly one
physical x/y/z bond. `F=sum_R exp(-iqR)X`, `Delta=F/Nc`,
`S=<F F^dagger>/Nc`, `mz2=Szz/Nc`. All brackets are ratios of complex `sum(sO)`
and `sum(s)`. Both Delta and S are saved; S is **not** the square of mean Delta.
`q=n1*Ly+n2`; `n1,n2` are dual-grid labels, and integer,
reciprocal-fraction and Cartesian momenta are in JSON. The full transform uses
the legacy 2-D FFT at `shear=0` and a staged x/phase/y FFT at `shear!=0`.

The real-space convention is
`C_mu,nu(d)=(1/Nc) sum_R X_mu(R) X_nu(R+d)` and the matching inverse is
`C(d)=sum_q exp(-i*q*d) S(q)/Nc`, with `d` reduced by the same quotient.

CSV stores equal-length raw phase/numerator blocks for all 9 complex S entries,
all 3 complex Delta entries and the P3 observables. JSON contains raw estimates,
Tr S, mz2, the largest eigenvalue of `(S+S†)/2`, and the raw Hermitian residual.
Only the eigenvalue calculation uses this Hermitian part. Negative noisy values
and all imaginary components are retained. Eigenvalues are computed **after**
ensemble averaging; their jackknife errors are exploratory near degeneracies.

`C_mu,nu(d)=sum_q exp(-iqd) S_mu,nu(q)/Nc`; `C_connected` subtracts
`<Delta_mu(0)><Delta_nu(0)>`. Every derived quantity is recomputed on each
joint delete-one-block phase/numerator ratio, including the uniform background.
The same implementation also pairs adjacent blocks repeatedly, without dropping
remainders. Larger-block estimates are diagnostics, not an independence claim.
The label `q` in `C_qINDEX_muNU` denotes the displacement's **cell index**, not
a momentum; exported correlation CSV gives explicit `dx,dy`.

## Optional mixing improvement

`--proposal bond-refresh` draws one entire single-bond open path from P2's exact
free Gaussian AR law, holding all other bonds fixed. Its normalized density is
`q_b(X_b)=Wph_b(X_b)*exp(omega*T/2)`, so the proposal-density ratio cancels the
phonon-weight ratio; acceptance remains `min(1,abs(Wf_new/Wf_old))`. All nodes,
factors and caches commit or roll back in the same P2 snapshot transaction.
The general MH ratio is also evaluated via independent AR transition densities.
One refresh sweep visits each bond path once, in random order (not each scalar
coordinate). No tuning or physical time-discretization change is involved.
This option was added after the h/2 local run showed a roughly 3-sigma Szz
discrepancy and insufficient blocking evidence. It is not a general large-system
accelerator: full dense factors and the physical Pfaffian are still rebuilt.

## Commands

Use the existing configured build/dependencies (GCC, Intel oneAPI/MKL, Eigen,
Boost). The FFT uses MKL DFTI; no optional Eigen FFT package is needed.

```bash
source /opt/intel/oneapi/setvars.sh
export OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_DYNAMIC=FALSE
cmake -S . -B build-kitaev-p01
cmake --build build-kitaev-p01 --target kitaev_ssh_mc kitaev_ssh_vbs_validate kitaev_ssh_mc_validate kitaev_ssh_phonon_validate -j 1
ctest --test-dir build-kitaev-p01 -R 'kitaev_ssh_p[234]|density_sign' --output-on-failure
mkdir -p build-kitaev-p01/p4_runs
build-kitaev-p01/kitaev_ssh_mc --vbs 1 --proposal bond-refresh --Lx 2 --Ly 2 --g 0.3 \
  --intervals 4 --dt 0.2 --seed 5201 --warmup 100 --sweeps 1600 \
  --measure-every 1 --block-samples 25 --output build-kitaev-p01/p4_runs/refresh_a
python kitaev_ssh/plot_vbs.py build-kitaev-p01/p4_runs/refresh_a_results.json \
  --output build-kitaev-p01/p4_runs/refresh_a_plots
```

Plotting needs NumPy/Matplotlib; this machine has
`/home/asus/.cache/pfqmc_plot_env/bin/python`. Set `MPLCONFIGDIR` to a writable
temporary directory if necessary. CMake is available here at
`/home/asus/code/driven-new-validation-20260908/green-residual/tools/cmake/data/bin/cmake`.
Outputs refuse overwrite. Plots read actual MC files and verify raw block sums.
The default plotted block level is the largest available with at least 16
blocks; override using `--block-samples`. No automatic plateau assertion is made.
`--candidate-from refresh_a_plots/vbs_analysis.json` fixes exploration momenta for
another seed with the same grid; it does not reselect peaks on the checking run.
Figures show every discrete momentum (including zero), inverse-FT connected
correlations with errors, and block-size error diagnostics. Raw complex data and
errors are exported alongside PNGs. No interpolation, synthetic physical plots,
negative clipping, or VBS/incommensurability claim is made.

`compare_vbs.py FIRST_results.json SECOND_results.json ... --output DIRECTORY`
plots fixed-grid independent-seed / T / h comparisons, with the candidates fixed
from FIRST. `verify_vbs_output.py *_results.json` independently recomputes inverse
FFT, eigenvalues and the full derived joint jackknife using NumPy and the saved
CSV blocks. Only pass VBS-enabled completed files, not old P3 outputs.

Tests cover uniform and plane-wave fields, MKL FFT vs real-coordinate direct
sums, translation, Parseval, inverse FT vs direct real-space products, exact
free-Gaussian covariance at L=2/4/6, and an independent complex-phase joint
jackknife comparison. These synthetic fields are tests only. Actual runs and
timings are in `build-kitaev-p01/p4_runs/*_results.json`.

value/error retained in CSV/JSON. This prevents the on-site vacuum variance
from hiding off-site correlations without changing or clipping any estimate.
