# ADR-006：先使用明确的关联比，不强制新增ξ/L或Binder

状态：现有关联比定义recorded；其他扩展proposed。
依据：H §11、FTS p5和DISCUSS；见[来源](../SOURCES.md)。

## 问题

需要无量纲量服务于驱动/尺寸标度，但非公度测量的窗口峰宽不自动等于物理关联长度。

## 已有定义

采用OBS-05的固定标量通道中心/邻点比。普通L×L下位移b1/L、b2/L；不把蜂窝坐标中的“一格”直接写成笛卡尔(2π/L,0)。保留正负邻点平均、共同相位和合法负值。

该量命名为窗口结构因子关联比。讲义自身p5也使用1−S(Δk)/S(0)；不因中文标题“关联长度比”就添加未经核验的ξ计算。

## 限制

非网格中心、形状和Q失配影响有限尺寸函数；比值不保证消掉这些影响。沿u+v=1的L=6一格邻点可接近另一共轭峰，不用它机械估单峰宽度。

Binder需要真正的四阶统计和明确复通道/背景/平移定义。现有二阶矩数据不能复原，λmax区块平方也不是Binder。本项目不以先实现Binder作为驱动接入前置条件。

## 影响与验证

当前可复用全网格和指定点矩阵；具体代码口径先查vbs_window.py及最新audit。后续若新增Binder或物理ξ/L，另写定义和验证，不仅改一个字段名。[OBSERVABLES](../OBSERVABLES.md)
