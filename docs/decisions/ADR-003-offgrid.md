# ADR-003：非网格平移平均与有限系统几何分开

状态：recorded。依据：H §5–8、§11；见[来源](../SOURCES.md)。

## 问题

目标Q非公度，不属于有限PBC动量网格，但仍需要测量与比较其结构因子。

## 记录的选择

保持给定Hamiltonian和周期几何，允许任意Q的有限Fourier测量；使用OBS-02的逐构型空间平移平均恒等式，从完整网格矩阵重建S_T(Q)。

固定原点的二阶量一般含不同网格动量交叉项；不能要求它与窗口和逐样本相等。平移平均与原物理期望等价需要相应系综对称性。

## 与剪切方案的关系

整数剪切改变有限连接和权重，是另一条几何选择。它不是测量重建的近似版本。固定形状剪切可标度，但没有普遍优于普通PBC的证据。

窗口加密不增加独立样本、不补出新的物理模式、不消除有限Hamiltonian公度效应。不使用“W=0即on-grid”的错误逆命题。
