# ADR-011：生产 Green 的按需精度与 LU 求解

日期：2026-10-06。状态：fast-1006 实现，本地对照通过。
来源：用户要求从当前 fast-1002 复制核心，并减少不必要的高精度和重复检查，优先提高速度。

## 选择

生产 signed 权重原本已接受 oblique Green 的相对纯态残差。
fast-1006 把同一检查移到扩展精度重算之前；已通过者直接继续，
也避免 prepared-right 路线因严格维度残差而重复 QR。
独立 strict/reference 默认仍按原维度残差检查。

生产 Green 使用 SVD 奇异值检查原 rank/rcond，再用 pivoted LU 求解。
无需生成只为 SVD 逆作用而使用的 U/V。double 求解残差不足时仍精化，
必要时仍由输入子空间用 long double 一致形成重叠、求解和 Green。
LU 首次失败时复用分解；扩展精度残差缓冲只在需要时构造，
最后一次迭代不再计算不会使用的修正。

这些是内部生产选项，没有新增用户 CLI 开关。原 rank/rcond、solve、
Green 及 phase/Pfaffian 门槛保持；Hamiltonian、Metropolis、相位重加权、
测量与统计定义保持。无法恢复的数值仍按原失败策略停止。
本条细化 ADR-010 的恢复触发策略，旧基线保存在 fast-1002。

## 证据与范围

保存的五个真实退出路径：合并权重、未合并完整测量、中心 Green 和能量
与重新编译的 fast-1002 参照逐项一致；完整回放合计约减少9.5%时间。
L6/M64 和 L9/M16 两条8样本链保持路径、接受/拒绝次数和全部可比较
物理输出；包括 fermion、VBSall 和 VBS 静态响应。单次采样耗时约减少
6.0%与9.6%，不能据此声明长链加速比例或统计收敛。

新增生产路径的8个病态合法 Gaussian 子空间对独立 MP50 参考最大
Green 相对误差6.04e-11；strict 原参考及既有权重/相位、失败事务回归通过。
Eigen/MKL 的 values-only SVD 与完整 SVD 的谱/rank 对照通过。
局部9案例×100重算的耗时31.0→1.87秒，扩展精度案例4→0；
这是局部基准，不是整条链的倍数。
