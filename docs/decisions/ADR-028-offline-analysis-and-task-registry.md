# ADR-028：原始块离线分析、统一任务表与诊断

日期：2026-10-23。状态：已实现本地 Python 工具；不修改生产采样器。

最终统计与采样进程原先耦合，最终汇总失败后仍需独立读取完成的原始块。
多端口、多种历史包装脚本及迁移/续算也需要同一个带来源的索引。

采用 `scripts/qmc.py analyze|diagnose|registry` 及共享 `qmc_tools` 模块。
只读工具直接消费完整的复相位原始块和显式元数据，单独写离线格式，不覆盖
原生产结果，不启动 MC，也不改变生产源码、二进制选择、运行设置和 seed。
因此不需要新的生产目标编译或预检作业。原来的 C++ 最终汇总入口仍保持原样；
已存在的旧维度错误通过按列名的离线统计恢复，不宣称已修改其内嵌实现。

统计约定保持共同复相位分母后再连接/求谱/作幅度非线性量；各独立链内删组，
恢复其原分配。粗分块保留每链短尾，按实际样本比例作加权 pseudovalue 方差；
等长块与既有 C++/Python 联合 jackknife 一致。所有来源、窗口、短尾和不定量显式输出。
身份缺失不猜测，续算祖先及重复 seed 不作独立链叠加。

任务表主键包含端口和完整 PBS 子任务 ID，状态观察带时间戳；缺席不等同完成。
多阶段 run start 记录优先选择明确名为 mc 的生产前缀；其他布局使用唯一 point
目录，遇到局部/全局下标时读取明确的 PBS 名称和 CHAIN_OFFSET 证据。
取数冻结完整行前缀，校验远端与本地 SHA256。

诊断是存储块尺度的描述性 rank/folded split Rhat 与相位比影响序列，不认证平衡。
不同弃样窗口逐项报告，不据结果自动挑选；不同物理/试探态/来源拒绝混合。

验收包括既有完整 C++ 原始/派生统计及相互作用结果交叉核对、已有最终汇总失败
数据的恢复、复杂相位/不等链长/短尾的独立删组参考、损坏数据和重复祖先拒绝，
以及现有两端任务与 L12 四条实际链的只读端到端使用。
