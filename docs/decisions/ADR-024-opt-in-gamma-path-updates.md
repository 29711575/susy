# ADR-024：可选 Γ 实模式完整开放路径更新

日期：2026-10-20；用户授权实现和固定预算 L6 消融。Γ 默认关闭，生产默认不变。

对每种键 μ，独立归一化基 e_mu(b)=delta_mu(b)/sqrt(Nc)。系数为
 a_mu(j)=sum_b e_mu(b)[X_jb-freeMean(j,b)]，其他空间模式保持。
独立三个事务分别尝试 x/y/z，不能把 Γ 当作两个实维的普通复 Fourier 模式。

开放声子参考均值使用原路径 freeMean（含原 trial 端点及任何已有源），不改
trial/source。协方差 C_ij=exp(-ωdt|i-j|)/(2mω)。每次从完整 AR 开放路径
独立抽 ξ（两个外端均自由，唯一中心），a'=sqrt(1-β²)a+βξ。
只沿对应空间基重建 X'，计算完整
 logMH=log|W(X')/W(X)|+logQ(a|a')-logQ(a'|a)。
Q 使用归一化首节点方差 β²/(2mω) 及后续 AR 条件方差
β²(1-exp(-2ωdt))/(2mω)，不是周期路径协方差。
理论上声子项与 pCN 反向密度抵消为 matter 比；Γ 实际判定保留完整 MH。
复用已验证的整路径候选/accept/reject/无缓存恢复及延迟相位测量事务。
非零 q 池继续禁止 Γ；新接口 --gamma-every 默认0，--gamma-beta 默认.5。

--q-mode-extra-pool 在原固定均匀池的一次尝试之后，额外逐项尝试冻结池。
不稀释原池频率。只有显式指定时启用，不改变旧随机数流。
--initial-path 只读坐标，严格比对声子/trial/source元数据，初始认证失败中止，
不按结果重抽。--mixing-diagnostics 为无 RNG 的全动量流及正式阶段计数/耗时。

最新 L6 原池经两个历史输入核对为(3,3),(3,2),(4,3)，xyz/beta.5，第一项
自共轭秩3、其余秩6。扩展池从6x6允许动量共轭去重得到19个非零族，
保留原3族，额外16族各每sweep一次；不沿用L9整数编号，无自适应预跑。
保持当前physical matter trial、Wilson++及固定奇偶+1；不与历史不相容
L6 trial 的物理结果静默合并。不实现副本交换。

证据：audit/1020/gamma-qpool-L6-ablation/。正确性、启动预检、正式混合结论
分别记录；提交阶段不能宣称混合改善。使用者要求提交HPC后停止等待。
