## 能量与奇偶

T 的键表沿用已验证 `static_vbs_response.py`，Majorana 基态能为
`-sum singular_values(T)`。默认固定原自由零位移 matter trial 的奇偶扇区，
用 det T 的相对符号判定是否加入最低单粒子能 `2 sigma_min`。该判断不
声称完成物理自旋投影。CLI `--parity unrestricted` 只作显式诊断。
全键梯度为 kX-gP；若有奇偶激发，P 包含相应奇异向量反射。
光滑基态支采用极分解的解析二阶导数；奇偶激发支用梯度差分并检查
最小奇异值简并。零模、不光滑、非正 Hessian 或未达梯度容差不认证响应。

## 响应与简并畴

`D_mu(q)=sum exp(-iq.r) X_mu(r)/Nc`，固定一个已松弛静态畴后，
`chi_mu,nu(q)=F_mu H_X^-1 F_nu^*/Nc`，外场约定 `-h sum fX`。
H_X 是全部键的 Hessian，其他键也随场松弛；非均匀背景不能只对一个
q 的能量子矩阵求逆。输出包含所有允许 q 和完整三键 Hermitian 响应。
相位 quadrature 用原始 cos 和 -sin 源，二者之和等于 Fourier 对角响应。
不减去 1/k，不借用有限投影期望的相位重加权定义，不报告 MC 误差。

平移破缺静态构型有精确平移简并。不同畴的 h=0 序参量不同，源符号
可选择不同畴；在严格零动能条件下，整个简并集合的左右导数可能不等。
因此有限的单畴 Hessian 响应不等于对称恢复后唯一的零场极化率。
软件保存序参量的平移畴范围并明确这一限制；不引入人工温度或展宽。
