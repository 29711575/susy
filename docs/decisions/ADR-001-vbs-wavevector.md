# ADR-001：Dirac动量差与VBS测量中心

状态：recorded。依据：P1 p3–4、P2 §B、H §2–4；见[来源](../SOURCES.md)。

## 问题

非公度VBS需要明确的波矢候选，但裸模型、均匀近似、有限系统允许点和实际量子峰不是同一个对象。

## 记录的选择

用QD=K+−K−≡2K̃ mod G作为有物理依据的候选，保留共轭对。原胞/Fourier约定和数值坐标以PHY-04/05为准；序参量定义以OBS-01为准。

不把候选强制替换成最近允许点，也不把裸QD写成所有耦合下的实际峰。完整动量数据用于独立检查候选附近和其他区域。

## 对速率比较的后果

相同终点、尺寸的R 与 2R比较应使用共同的Q/通道规则。按每个速率样本最高峰换点，是另一种经过优化的观测量，不能悄悄混入原速率比。

这条比较规则是已讨论的方案约束，不宣称目前已获得驱动数据。
