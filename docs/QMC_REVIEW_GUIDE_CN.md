整理日期：2026年11月16日。面向首次接触本项目的研究者。对应仓库主分支基础提交 `b085974c18b5db4935536aa4fe84b5f778428cc5`；本次只整理文档，没有修改算法或重跑计算。

## 1. 研究对象与计算范围

程序研究蜂窝晶格上的 Kitaev 自旋模型与键声子的耦合。在固定规范场后，自旋模型中的物质自由度用 Majorana 费米子表示，每条键上保留一个实声子坐标。Hamiltonian、Majorana 归一化、键方向和规范符号的精确定义见[物理约定](PHYSICS_CONVENTIONS.md#phy-01-hamiltonian-与规范范围)。

| 参数或名称 | 本项目中的含义 |
|---|---|
| `Lx, Ly` | 两个晶格方向的原胞数。方形序列 Lx=Ly=L 含 L² 个原胞、2L² 个 Majorana 格点和3L²条键 |
| `Jx, Jy, Jz` | 三类键的交换耦合 |
| `X`、`g` | 键声子坐标和线性耦合常数；有效键耦合为 Jμ+gX |
| `mass`、`omega-ph` | 声子质量 m 和频率 ω；弹性常数 k=mω² |
| λ | J=1 单位下定义为 g²/k；不是直接输入的独立命令行参数 |
| `intervals`、`dt`、τ | 虚时间区间数、步长和总长度；τ=intervals×dt。中心测量点距两端各τ/2 |
| 规范场、Wilson 扇区 | 规范键变量及周期方向的全局边界扇区；常见数据使用零通量、两个 Wilson 值均为+1 |
| `matter-trial physical` | 按固定规范场和几何选择满足费米子宇称条件的试探态；必要时占据一个最低能准粒子 |

费米子宇称表示费米子数的奇偶性。选对宇称使固定规范态的物理投影可以非零，但不等于显式完成所有自旋约束的投影，也不证明已找到所有规范扇区中的最低能态。程序抽样时不扫描全部规范场；这是理解结果范围的重要前提。

## 2. 投影路径与权重

这里使用开放虚时间路径，两端给定试探态，在中间测量。它不是有限温度周期路径，τ不能直接当作逆温度β。声子路径两侧的坐标可以独立变化，不能人为强制镜像来保证权重为正。

声子部分使用谐振子的精确虚时间传播核，称为 Mehler 核，并包含端点试探波函数。给定声子路径后，费米子部分由有序的二次 Hamiltonian 传播得到。相关实现依次在 `phonon_path.h`、`phonon_projector.h` 和 `inc/pure_projector_*.h` 中。

精确声子传播核不意味着耦合问题没有时间离散误差。费米子与声子耦合的离散传播及测量仍需检查 dt 收敛。传播因子的符号、左右作用顺序、端点半步以及中心测量位置应结合[正确性验证说明](PFQMC_CORRECTNESS.md)和独立多体参考程序检查，不能只凭矩阵变量名判断。

费米子重叠用 Pfaffian 计算，可能带符号或复相位。抽样使用完整权重的绝对值；测量时保留相位并重加权。程序可以在提议阶段只计算绝对值、测量时再计算相位，这只是计算安排，不是把相位丢弃。

## 3. 一次更新如何完成

`PhononSampler` 在[phonon_mc.h](../kitaev_ssh/phonon_mc.h)中管理路径提议、权重计算、接受或拒绝及计数。一般 Metropolis–Hastings 接受概率包含新旧权重绝对值比与正反提议概率比。某些提议按自由声子分布构造，使声子部分与提议概率抵消；有参考力的提议还必须保留相应修正，不能一概只取费米子权重比。

| 更新方式 | 改变的变量 | 阅读入口 |
|---|---|---|
| 单节点更新 | 一条键在一个虚时间节点的坐标 | `attempt`及声子条件分布 |
| 整键路径更新 | 一条键的全部时间节点 | `attemptBond`、`attemptGuidedBond`，以及 `phonon_guided_proposal.h` |
| 固定非零动量更新 | 多条键按指定空间模式共同变化 | `attemptQMode`、`phonon_q_mode.h` |
| 零动量更新 | 空间均匀的声子模式 | `phonon_gamma.h`、`attemptQMode`中的零动量分支 |

具体函数名见[代码地图](CODE_MAP.md)，以源码声明为准。更新使用的动量是抽样设置，测量峰值动量是从关联函数得到的结果，两者不是同一概念。程序包含的可选零动量更新也不等于后续计算使用的多尺度三通道更新；后者不在本仓库核心中。

接受后必须同时提交新路径和相应缓存，拒绝后必须保留旧状态。缓存指重复使用先前计算的传播矩阵等中间结果。审阅时应检查缓存与直接重新计算是否一致，特别是连续拒绝、数值恢复以及从检查点继续计算的情况。

数值计算无法可靠得到权重时，程序先对同一提议使用参考方法重新计算，无法恢复则报错中止。这与一次正常的物理拒绝不同，不能将数值失败视为零权重后继续抽样。

## 4. 测量量和统计处理

VBS 是 valence-bond solid 的缩写，通常译为价键固体。在本程序中，以键声子场的空间调制作为相关测量。`Szz` 的 z 表示 z 方向键的声子通道，**不是自旋 SzSz 关联**。精确定义与归一化集中在[观测量定义](OBSERVABLES.md)，不要从列名中的字母猜测。

| 量 | 含义和主要限制 |
|---|---|
| 结构因子与 m² | 中心声子 Fourier 振幅的二阶矩；m²包含除以原胞数的归一化。固定动量结果和全非零动量最大值须分别报告 |
| 三键矩阵 | x、y、z 三种键通道的关联矩阵。应先统计平均矩阵，再求特征值 |
| 静态场响应 χ | 对施加在整个投影路径上的外场求导，保持端点试探态不变；有限τ下不是自动等同于基态响应 |
| 模长及四阶矩 | 对同一构型的 Fourier 振幅取模后测量；不能用二阶矩的平方替代四阶矩 |
| 关联比 | 固定中心动量和邻近动量的结构因子之比；可为负，不应自动裁为零，也不自动等于关联长度除以L |
| `majorana_energy` | 费米子及其声子耦合的能量，不含完整声子能量 |
| `energy_total`等六个能量量 | 由单独开关启用，在中心附近声子传播区间的中点插入；不能直接把不同测量位置的旧能量项相加 |

每个量保存相位加权的分子和共同相位分母，先求两者之比，再做连接部分减法、关联比或特征值等非线性操作。不能先对各链的比值作简单平均，也不能将复相位替换成绝对值。

`phase_statistics.h`处理单链的等长统计块；离线分析还可按独立随机种子删除整条链来估计误差。Jackknife 指每次删除一个统计单元后重新计算结果的误差估计方法。统计单元究竟是链内块还是独立链，必须看具体报告。若报告使用全动量最大值，每次删除后也应重新选最大值。

连续保存的测量一般相关，保存数量不等于有效独立样本数。只有相位加权总和的压缩结果，也不能恢复逐步自相关或任意更改前段舍弃长度。继续计算的统计已包含旧段，不能再与旧段重复相加。

“减去均匀系综均值”和“从每个构型删除整个均匀模式”是两种不同操作。[观测量定义](OBSERVABLES.md#obs-03-rawconnectedprojected)保留了它们的公式。自由声子涨落可用作解析参考，不应未经说明从相互作用结果中扣掉。

## 5. 已有验证能说明什么

[2026-10-30 验证记录](../evidence/source-sync-20261030/README.md)保存当时重新构建后的日志，包括40组独立核心参考案例、端点传播比较和谱安全检查。Python 统计回归共发现19项，15项通过，4项因未提供历史本地样本而跳过。原工作区的旧执行记录另行保存，不算本次重新执行。

另外还有自由声子解析检查、小系统完整费米子 Fock 空间对照、缓存接受/拒绝对照、物理宇称检查和相互作用小系统精确对角化程序。Fock 空间指显式列举费米子占据态构成的多体空间。这些方法、输入和运行范围见[正确性说明](PFQMC_CORRECTNESS.md)及[材料索引](REPORT_INDEX_CN.md)。有验证源码不等于全部测试已在当前版本和所有参数上执行。

审阅建议分别回答三个问题：离散模型的计算是否正确；实际链是否充分抽样；τ、dt、尺寸和试探态的系统误差是否受控。第一项通过不能代替后两项。程序正常结束、平均相位接近1或接受率较高，都不足以单独判断平衡或临界性。

## 6. 推荐的审阅顺序与待检查问题

先用[代码地图](CODE_MAP.md)逐步读模型、路径、抽样、权重、测量和统计，再对照独立验证。首次阅读不需要按日期通读全部历史报告，也不需要运行大型计算。

值得重点检查的问题包括：固定规范场与物理宇称条件是否一致；传播顺序与中心插入是否一致；提议密度修正和拒绝后的状态恢复是否完整；相位分母和派生量误差是否联合计算；实际数据能否支持热化、时间离散和投影收敛的结论。

临界指数与超对称性（supersymmetry，SUSY）的讨论属于进一步物理分析。图中的2/3或5/3参考斜率不是代码正确性的判据，也不是已发现相应普适行为的证明。不同尺寸的试探态、离散动量和低能谱可能不同，见[尺寸与短虚时间分析](FINITE_SIZE_AND_SHORT_TIME.md)及[11月9日具体案例](../audit/1109/README.md)。
