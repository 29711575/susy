## 建议先读的材料

1. [QMC 代码审阅说明](QMC_REVIEW_GUIDE_CN.md)：无需开发背景的模型、算法、统计和限制说明。

3. [物理约定](PHYSICS_CONVENTIONS.md)与[观测量定义](OBSERVABLES.md)：需要检查公式、符号、归一化时使用。
4. [2026-10-30 验证记录](../evidence/source-sync-20261030/README.md)：查看实际编译和确定性检查的结果。
5. 按具体研究问题选择下面的结果报告。

上述专门技术文档中的编号用于引用具体条款；它们不表示不同模型或不同版本。文中的“试探态”对应源码 `trial`，“物质费米子”对应 `matter`；更早材料还保留了一些开发时的英文简称。

## 静态计算：单独阅读

[limit/README.md](../limit/README.md)是绝热极限代码和结果入口。静态计算求声子坐标的能量极小值及响应，不含有限频率的声子量子路径抽样，不能与 QMC 的有限τ测量直接混作一个数据集。

这里包含 Jz=0.5 的 L=6–9 共208点，以及11月10日 Jz=0.6 的 L=3–10 数据。后者240个计划点中238点通过所列验证，L=10、λ=0.1/0.2的响应仍待核查。静态优化达到所列精度，也不等于证明全局最低能解。
